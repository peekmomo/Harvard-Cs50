# CS50 英语词汇 20 词

## 1. syntax

**发音：** syntax\
**意思：** 语法；语法规则

**短句：**\
JavaScript has a simple syntax.\
（JavaScript 有着简单的语法。）

------------------------------------------------------------------------

## 2. semantics

**发音：** semantics\
**意思：** 语义；含义

**短句：**\

------------------------------------------------------------------------
