
 1. framework

Pronunciation: /ˈfreɪm.wɜːrk/

Chinese meaning: 框架；体系；架构

Programming meaning

In programming, a framework is a set of tools, rules, and structures that helps you build applications in a more organized way.

Examples

Next.js is a React framework.
Next.js 是一个 React 框架。

This framework makes web development easier.
这个框架让 Web 开发更容易。

We need a clear framework for the project.
我们需要一个清晰的项目架构。

Memory tip

frame = 框架、架子

work = 工作

framework ≈ 支撑工作的架子 → 框架

framework vs library

library：库，你主动调用它。

framework：框架，它会规定项目整体结构和开发方式。

For example:

React is closer to a library.

Next.js is a framework.

2. decorator

Pronunciation: /ˈdek.ə.reɪ.tər/

Chinese meaning: 装饰者；装饰工；装饰器

General meaning

A decorator can mean a person whose job is to decorate rooms or buildings.

Example:

interior decorator = 室内装饰师

Programming meaning

In programming, a decorator is used to add extra behavior or functionality to a function, method, or class without directly changing its original code.

Python example

@app.route('/api/users')
def get_users():
    ...

Here:

@app.route('/api/users')

is a decorator.

You can understand it as:

decorator = 给原来的东西“外面再加一层功能”

Example sentence

The decorator adds extra behavior to the function.
这个装饰器给函数增加了额外的行为。

Related words

decorate = 装饰

decoration = 装饰；装饰品
